# WalkScope 前端

Vue 3、TypeScript、Vite。安装、启动、样例边界与完整验证步骤见项目根目录 [README](../README.md)。前端使用 Node 24，从本目录运行 `npm ci`、`npm test`、`npm run build`；开发启动运行 `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`。

复制 `.env.example` 为 `.env.local`。服务端密钥不得放入任何 `VITE_` 变量。道路底图所用浏览器 AK 属于公开客户端配置，应设置 Referer 限制。没有地图 AK 时可查看保存数据的空间示意。
